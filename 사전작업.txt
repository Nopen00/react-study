npm create vite@latest hello-react-project

=====================================

vite : 빌드도구
	개볼중 작성한 여러개의 파일을 하나 또는 몇 개로 묶는 도구

ESList : 문법검사

=====================================

> create-vite hello-react-project

│
◇  Select a framework:
│  React
│
◇  Select a variant:
│  TypeScript + React Compiler
│
◇  Which linter to use?
│  ESLint
│
◇  Install with npm and start now?
│  Yes

=====================================

npm run dev: 작성하는 코드가 실시간으로 반영된(개발 시 사용)

개발 종료 후 bulid

npm run build : 서버에 올려서 사용자들에게 웹페이지로 배포될 파일들로 코드를 모아 컴파일
	> dist 폴더 생성

npm run preview : build를 통해 나온 결과물을 테스트 하는 단계
